# Amin Elayed — Portfolio Presentation & Live Works Showcase

A high-performance, curated portfolio website highlighting 10 real production web platforms, AI systems, and interactive experiences engineered by **Amin Elayed**.

## ✨ Features
- **Curated Selection**: 10 authentic production websites across hospitality, combat sports, Web3, and AI.
- **Embedded Live Previews**: Each project can be previewed directly in an interactive responsive device frame (Desktop, Tablet, Mobile) without broken iframes.
- **Deploy-Ready for Netlify**: Zero-build static bundle ready to deploy with 1-click on Netlify or GitHub Pages.

1. **Restaurant des Arts** — Mediterranean dining & reservation site (Cité de la Culture)
2. **Nüma Coffee Kitchen** — Botanical specialty coffee & brunch (Menzah 8)

10. **Velocity Mental Math** — Flutter Web high-speed arithmetic speed trainer

## 📦 Deploying to Netlify
1. Connect this repository to [Netlify](https://www.netlify.com).
2. Set **Publish directory** to `.`.
3. Deploy! Or drag-and-drop this entire folder into [app.netlify.com/drop](https://app.netlify.com/drop).
